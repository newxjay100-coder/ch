# 천주교 서울대교구 한강성당 공식 홈페이지 (Hangang Catholic Church)

> **천주교 서울대교구 제1 중구-용산지구 지구좌성당 한강성당 공식 홈페이지 리디자인 프로젝트**  
> 주보성인: 성 김대건 안드레아 사제 순교자  
> 위치: 서울특별시 용산구 이촌로81길 38 (이촌동 248)

---

## 🌟 주요 기능 및 특징

1. **디지털 성전 아이덴티티 및 에디토리얼 레이아웃**
   - 붉은 벽돌과 스테인드글라스, 파이프오르간 찬송가 오디오 플레이어
   - 성령의 빛 마우스 커서 팔로우 인터랙션
   - Noto Serif KR / Pretendard 기반 타이포그래피

2. **메인 페이지 핵심 구성**
   - **히어로 섹션**: 예레미야 29,12 말씀 & 플로팅 오늘의 복음/전례 묵상 카드
   - **6개 퀵 메뉴**: 오늘의 미사, 이번 주 주보, 본당 일정, 오시는 길, 혼인성사, 처음 오셨나요?
   - **3컬럼 에디토리얼 그리드**: 미사 안내(주일/평일 탭), 소식/공지 및 2027 WYD 코랄 배너, 2026 10월 본당 달력
   - **트윈 배너**: 한강본당 50년사 (1970–2020) 디지털 e-Book 열람 및 한강성당 소개
   - **한강갤러리**: 본당 행사, 신앙생활, 본당의 오늘 실물 사진 그리드 & 고화질 라이트박스 뷰어
   - **성미술 투어**: 최종태 요셉 십자고상, 최봉자 수녀 성모자상, 양승준 교수 스테인드글라스 등
   - **혼인성사 안내**: 대성전 혼인미사 안내 및 인앱 상담 신청
   - **오시는 길**: 이촌역 3-1번 출구 도보 5분 안내 & 네이버 지도 연동

3. **인앱(In-App) 통합 연동 시스템**
   - **네이버 지도 인앱 뷰어 (`NaverMapModal`)**: 외부 이탈 없이 웹사이트 안에서 실시간 길찾기/대중교통/주차 안내
   - **50년사 e-Book 리더 (`HistoryEbookModal`)**: 반세기의 역사와 사진을 책장 넘기듯 열람
   - **성당 대표 메일 문의 (`ParishEmailModal`)**: `office@hankang.or.kr` 연동 문의 작성 폼
   - **35개 세부 서브페이지 브라우저 (`SubPageViewer`)**

## 🚀 개발 및 실행 방법

### 1. 패키지 설치
```bash
npm install
```

### 2. 로컬 개발 서버 실행
```bash
npm run dev
```
브라우저에서 `http://localhost:5173/` 접속

### 3. 프로덕션 빌드
```bash
npm run build
```
`dist/` 디렉터리에 빌드 결과물 생성 (상대 경로 `./` 기반으로 어떤 호스트/포트에서도 동작)
